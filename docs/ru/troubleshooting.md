# Решение проблем

## `ENDPOINT PING` показывает `?`

Это пинг до адреса эндпоинта, и ему нужен ICMP-сокет, который текущему пользователю разрешено открыть. `TUN PING` это не затрагивает никогда, и ранжирование с `-P` продолжает работать - колонка просто показывает `?`.

На большинстве систем разрешение уже есть, поэтому сначала проверьте:

```sh
cat /proc/sys/net/ipv4/ping_group_range   # "0 2147483647" = разрешено, "1 0" = закрыто
```

Если закрыто, либо выдайте программе capability, либо откройте диапазон системно:

```sh
sudo setcap cap_net_raw+ep ./warpscout

# или
sudo sysctl -w net.ipv4.ping_group_range="0 2147483647"
```

В Docker см. [соответствующий раздел](docker.md).

## Программу убивают на маленьком роутере

Это OOM killer ядра, поэтому оболочка сообщает голый `SIGKILL`, а сама программа не печатает ничего. `dmesg`, или `logread` на OpenWrt, это подтверждает:

```
Out of memory: Killed process 4650 (warpscout) total-vm:1570964kB, anon-rss:176768kB
```

WARPSCOUT по умолчанию ограничивает память рантайма Go значением `32MiB` - этого хватает даже на полное сканирование с `-f`, так что происходить такого больше не должно. Если всё-таки происходит, лимит опускается переменной `GOMEMLIMIT`:

```sh
GOMEMLIMIT=8MiB warpscout scan -p awg -gen-i1 quic -f
```

`8MiB` - осознанная нижняя граница. Ослаблять лимит смысла нет: время сканирования от этого не меняется.

## macOS отказывается запускать файл

Файл скачан из интернета, снимите флаг карантина один раз:

```sh
xattr -d com.apple.quarantine warpscout
```

## Всё падает с `-p wg`

В фильтрующей сети это нормально. Используйте `-p awg`, а если и он не сработает - идите по списку в разделе [обход блокировок](blocking.md).

## Уведомление о новой версии не пропадает или мешает

Любая команда, кроме `version`, проверяет наличие нового релиза и печатает уведомление. Ответ кэшируется на 6 часов в `$TMPDIR/warpscout-latest-version-<uid>` - это `/tmp` на Linux, `$PREFIX/tmp` в Termux, персональный `/var/folders/…/T/` на macOS и `%TEMP%` на Windows. Удалите файл, чтобы проверка прошла заново.

## Живая панель ломается или не рисуется

Добавьте `-plain` - построчный вывод вместо живой панели. Он же нужен, когда вывод уходит в файл или в другую программу.
