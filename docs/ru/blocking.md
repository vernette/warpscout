# Обход блокировок

[← Назад к README](../../README_RU.md)

DPI узнаёт WireGuard по рукопожатию. AmneziaWG (`-p awg`) ломает это двумя способами: подмешивает к настоящему трафику мусорные пакеты и открывает соединение выдуманным первым пакетом (`I1`), который притворяется протоколом, который никто не блокирует.

## Обычно решает первый пакет

Основную работу делает `I1`. DPI склонен судить о соединении по тому, как оно начинается, поэтому сессия, открывшаяся чем-то похожим на QUIC или DNS, часто проходит, а она же с другими размерами junk - нет. **Если эндпоинты блокируются, меняйте сначала `I1`.**

По умолчанию `I1` имитирует запрос iCloud. Другие варианты генерируются флагом `-gen-i1`:

```sh
warpscout scan -p awg -P -gen-i1 quic
warpscout scan -p awg -P -gen-i1 dns -i1-sni example.com
```

`-gen-i1` принимает `quic`, `dns`, `sip`, `stun` или `random`. Начинать стоит с `quic`, он чаще всего работает. `-i1-sni` задаёт имя хоста, которое упоминает поддельный пакет; без него берётся случайный известный хост.

Можно также подсунуть сырой пакет через `-i1 PKT` или не отправлять никакого через `-i1 none`.

## Мусорные пакеты

Ими управляют три числа:

| Флаг        | Значение                                             |
| ----------- | ---------------------------------------------------- |
| `-jc N`     | Сколько мусорных пакетов отправлять (по умолчанию 6) |
| `-jmin N`   | Наименьший размер мусорного пакета (по умолчанию 10) |
| `-jmax N`   | Наибольший размер мусорного пакета (по умолчанию 50) |
| `-gen-junk` | Выбрать все три случайно для этого запуска           |

В большинстве сетей сработают значения по умолчанию. Сами по себе они редко что-то разблокируют, поэтому всегда начинайте с `-gen-i1`.

## Автоматический подбор: find-junk

Если ни один профиль `-gen-i1` не помог, значит под сеть надо подгонять и числа junk. `find-junk` ищет рабочий набор сам:

```sh
warpscout find-junk -gen-i1 random
```

`-gen-i1` стоит добавлять всегда: без него поиск оставляет первый пакет одинаковым на каждой попытке, а именно он чаще всего и решает.

Команда пересканирует раз за разом со свежими случайными настройками, пока какой-нибудь набор не поднимет хотя бы `-threshold` процентов взятых эндпоинтов (по умолчанию 95). Затем печатает готовую строку `warpscout scan ...` с рабочими настройками - остаётся скопировать и запустить. `Ctrl+C` или `q` в любой момент сохраняет лучший найденный набор.

![find-junk в WARPSCOUT](../../.github/assets/warpscout-find-junk.png)

Команда работает только с AmneziaWG и проверяет эндпоинты одними рукопожатием и пингом, поэтому колонки региона и ноды остаются пустыми.

## Если AmneziaWG не проходит совсем

Остаётся [MASQUE](masque.md) - второй транспорт Cloudflare. В варианте `-p masque-h2` он идёт поверх TCP и снаружи выглядит как обычный HTTPS.
